# What you can't do (yet)

These are the jobs [`NpcControl`](taking-and-releasing-an-npc.md) does not cover for an [NPC](../npcs.md) (a character in the game).

- You can't change an NPC's animation, sound, look or state. Only the five parts the flags name are changed (see [What each flag changes](what-each-flag-changes.md)).
- Taking the NPC does not stop a walk the game already started. A walk that started before the take finishes or stops by the game's own rules. Only the hold stops new activity.
