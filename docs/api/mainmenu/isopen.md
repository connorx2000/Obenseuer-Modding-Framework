# IsOpen

`IsOpen` is the [`MainMenuButtons`](mainmenubuttons.md) property to check before your mod shows something over the main menu.

- `IsOpen` is `true` when the main menu is up and your buttons have been built on it. It is `false` before the menu exists, while it is loading, and when no menu button could be copied.
